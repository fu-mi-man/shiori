# 要件定義

## 1. サービス概要

**サービス名**: 旅のしおり作成サービス(仮)

**コンセプト**: 
旅行の行程表を簡単に作成し、URLで共有できるWebサービス。
「行程さん」のようなシンプルで使いやすいUIを目指す。

**ターゲットユーザー**: 
- 友人や家族と旅行を計画する人
- グループ旅行の幹事
- 旅行の予定を可視化したい人

---

## 2. 機能要件

### 2.1 必須機能

#### しおり作成
- タイトル入力
- 概要の入力(複数項目追加可能)
  - タイトル + 内容(旅費、持ち物、ホテル情報など)
- 行程の入力(複数項目追加可能)
  - 日付、時間
  - 日数(任意: 1日目、2日目など)
  - タイトル(場所名、イベント名)
  - 交通手段選択(徒歩/電車/バス/飛行機/車/船/自転車)
  - 補足(詳細情報)

#### しおり表示
- **タイムライン形式で視覚的に美しく表示**
  - 時系列に沿った縦方向のレイアウト
  - 交通手段アイコンを見やすく配置
  - 日数表示（1日目、2日目など）をサポート
- 概要セクションと行程セクションを分けて表示

#### しおり編集
- 作成後にしおりを編集可能
- 合言葉(パスワード)による編集制限

#### URL共有
- 一意のURLを生成(例: https://yoursite.com/i/abc123)
- URLを知っている人は誰でも閲覧可能
- URLコピー機能
- LINE共有ボタン(検討中)

#### 合言葉(パスワード)機能
- 任意で合言葉を設定可能
- 合言葉を知っている人のみ編集可能
- パスワードはハッシュ化して保存

#### 自動削除
- 最終アクセスから3ヶ月後に自動削除
- データの無期限保持を防ぐ

---

### 2.2 あったらいい機能(後回し)

#### QRコード生成
**機能**: 共有URLをQRコードに変換して表示

**ユーザーの利点**:
- 対面で友達にURLを共有する時、スマホで読み取るだけで簡単
- URLをコピペしてLINEで送る手間が不要
- 印刷してメンバーに配布できる

---

#### PDF出力
**機能**: 作成したしおりをPDF形式でダウンロード

**ユーザーの利点**:
- 印刷して紙で持ち歩ける
- 電波が届かない場所(山、海外など)でもオフラインで見れる
- スマホのバッテリーを気にせず確認できる
- 記念として保存できる

---

#### テンプレート機能
**機能**: よくある旅行パターンのテンプレートを提供

**例**:
- 国内1泊2日テンプレート
- 国内2泊3日テンプレート
- 海外3泊4日テンプレート
- 日帰り旅行テンプレート

**ユーザーの利点**:
- ゼロから作らず、テンプレートを選んで項目を埋めるだけで完成
- 作成時間を大幅に短縮できる
- 旅行の行程の漏れを防げる(チェックイン時間、集合時間など)

---

#### カラーテーマ選択
**機能**: しおりの配色テーマを選択できる

**例**:
- ブルー系（爽やか・海）
- ピンク系（かわいい・華やか）
- グリーン系（自然・リラックス）

**ユーザーの利点**:
- 旅行のイメージに合わせてデザインをカスタマイズできる
- 個性的なしおりが作れる
- 複数のしおりを作る時に区別しやすい

---

#### 写真挿入機能
**機能**: 概要や行程に写真を挿入できる

**ユーザーの利点**:
- 観光地の写真を入れることで旅のイメージが湧きやすい
- ホテルや飲食店の外観写真で場所を特定しやすい
- 視覚的に魅力的なしおりになる
- 記念として見返す楽しみが増える

**技術的考慮**:
- 画像ストレージの容量管理が必要
- 外部ストレージサービス（Cloudflare R2、Supabase Storageなど）の利用を検討

## 3. 画面一覧

### トップ画面
- サービス説明
- 「しおりを作る」ボタン
- サンプル表示(任意)

### 作成画面
- タイトル入力フォーム
- 概要入力エリア(追加・削除可能)
- 行程入力エリア(追加・削除可能)
- 合言葉設定(任意)
- 「完了」ボタン

### 完成画面(プレビュー)
- 作成したしおりのプレビュー表示
- 共有URL表示
- 「URLをコピー」ボタン
- 「編集に戻る」ボタン

### 表示画面(共有URL)
- しおりの内容を表示(閲覧専用)
- 「このしおりを編集」ボタン(合言葉入力)

### 編集画面
- 作成画面と同じUI
- 合言葉が必要(設定している場合)
- 「更新」ボタン

## 4. データ項目

### しおりテーブル
| 項目 | 型 | 説明 |
|------|-----|------|
| id | UUID | 一意のID(URLに使用) |
| title | String | しおりのタイトル |
| overview | JSON | 概要データ(配列) |
| schedule | JSON | 行程データ(配列) |
| password_hash | String | 合言葉のハッシュ値(任意) |
| created_at | DateTime | 作成日時 |
| last_accessed_at | DateTime | 最終アクセス日時 |

### overview (JSON構造)
```json
[
  { "title": "旅費", "content": "1人あたり50,000円" },
  { "title": "持ち物", "content": "着替え、充電器..." }
]
```

### schedule (JSON構造)
```json
[
  {
    "date": "2025-01-15",
    "day_number": 1,
    "time": "08:00",
    "title": "東京駅集合",
    "transport": "train",
    "note": "8:30までに集合"
  }
]
```

**補足**:
- `day_number`: 任意項目。1日目、2日目などの表示に使用
- 日付と併せて「2025-01-15（1日目）」のように表示可能

## 5. 非機能要件

### デザイン・UI
- **モバイルファースト設計（必須）**
  - スマホでの使いやすさを最優先
  - タップしやすいボタンサイズ（最低44x44px）
  - スクロールのスムーズさ
  - 入力フォームの使いやすさ
- **タイムライン表示の強化（必須）**
  - 時系列に沿った縦方向レイアウト
  - 移動手段アイコンを見やすく配置
  - 時間・日付の明瞭な表示
  - 視覚的に美しいデザイン
- スマホ幅固定デザイン(max-width: 480px程度)
- PC表示でも中央に配置
- シンプルで直感的なUI

### ブラウザ対応
- Chrome(最新版)
- Safari(最新版)
- Firefox(最新版)
- Edge(最新版)

### セキュリティ
- 合言葉はハッシュ化して保存(bcrypt等)
- SQLインジェクション対策
- XSS対策

### パフォーマンス
- ページ読み込み: 3秒以内
- API応答時間: 1秒以内

### その他
- アカウント登録不要
- メールアドレス不要
- 完全無料
