## 2. 画面遷移

### MVP

```text
トップ (/)
  └─[しおりを作る]→ 作成画面 (/create)
                      ├─[完了]→ 閲覧画面 (/i/[id])
                      └─[AIでつくる]→ 条件入力ダイアログ →（生成・登録）→ 閲覧画面 (/i/[id])

閲覧画面 (/i/[id])
  ├─[URLをコピー]→ クリップボードにコピー
  ├─[編集]→ 編集画面 (/i/[id]/edit)
  └─[同じ条件でもう一回]→（AI生成しおりのみ。再生成して上書き）

編集画面 (/i/[id]/edit)
  ├─[更新]→ 閲覧画面へ
  └─[キャンセル]→ 閲覧画面へ
```

AI行程作成の詳細は `../../02_specification/ai-plan-generation.md` を参照。

### MVP以降（合言葉・閲覧権限の追加後）

```text
閲覧画面 (/i/[id])
  ├─ visibility: public → そのまま表示
  └─ visibility: private → 合言葉入力画面 → 閲覧画面

編集画面 (/i/[id]/edit)
  ├─ 合言葉未設定 → そのまま編集画面
  └─ 合言葉あり → 合言葉入力画面 → 編集画面
      （直アクセスも合言葉入力画面にリダイレクト）
```


## 3. 実装しない機能

| 機能 | 理由 |
|------|------|
| 外部サービス連携（乗換案内など） | 実装コスト高、ユーザーが自分で検索して入力する方がシンプル |
| コメント・チャット機能 | LINEなど既存ツールで代替可能 |
| 割り勘連携 | 旅のしおりの本質から外れる |


## 4. MVP機能一覧

| 機能 | 画面 | 詳細 |
|------|------|------|
| しおり作成 | 作成画面 | タイトル・概要・行程を入力して作成 |
| しおり閲覧 | 閲覧画面 | タイムライン形式で表示 |
| しおり編集 | 編集画面 | 作成時と同じ項目を編集 |
| URL共有 | 閲覧画面 | URLをコピーボタン |
| トップページ | トップ画面 | サービス紹介、作成への導線 |
