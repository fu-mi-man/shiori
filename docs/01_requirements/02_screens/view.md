## 概要

作成したしおりを閲覧する画面。URLを知っている人は誰でもアクセスできる。

- **URL**: `/i/[id]`
- **デザイン**: `designs/view-page.pen`

## MVP機能

- タイムライン形式でしおりを表示
- URLをコピーして共有
- 編集画面への遷移

## UI仕様

### レイアウト

- max-width: 480px、中央配置

### セクション構成

| セクション | 内容 |
|-----------|------|
| ヘッダー | しおりのタイトル、日付範囲（schedulesのdateからMIN/MAX算出） |
| CTAボタン | URLをコピー、編集ボタン |
| 概要 | タイトル + 内容のカードリスト |
| 行程 | タイムライン形式（日数バッジ + 日付、ドット + 縦線、時間、場所、補足） |

### 操作仕様

- 「URLをコピー」ボタン → クリップボードにコピー → トースト通知
- 「編集」ボタン → 編集画面（`/i/[id]/edit`）に遷移
