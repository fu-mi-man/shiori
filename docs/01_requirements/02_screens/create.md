## 概要

旅行のしおりを新規作成する画面。

- **URL**: `/create`
- **デザイン**: `designs/create-page.pen`

## MVP機能

### 入力項目

| セクション | 項目 | 必須 | 備考 |
|-----------|------|------|------|
| タイトル | しおりのタイトル | ✅ | 最大255文字 |
| 概要 | タイトル + 内容 | - | 最大10件。内容は最大500文字 |
| 行程 | 日付、日数、時間、タイトル、補足 | - | 最大10日、1日あたり最大20件。すべて任意。補足は最大200文字 |
| 合言葉 | 編集用パスワード | - | MVP後に実装 |

> **設計方針**: 必須項目は最小限に。「必須項目を減らす → しおり完成まで到達する人数を増やす」「エラーを出さない設計」に倣う。

### 出力

- 一意のID（UUID）を生成
- 共有URL（`/i/[id]`）を発行
- 作成完了後、閲覧画面に遷移

## UI仕様

### レイアウト

- max-width: 480px、中央配置

### セクション構成

- タイトル入力
- 概要セクション（動的に追加・削除可能）
- 行程セクション（日数ごとにグループ化、動的に追加・削除可能）
- 合言葉入力（MVP後に実装）
- 完了ボタン

### 操作仕様

- 概要・行程は「追加」ボタンで動的に追加、「削除」ボタンで削除
- 必須項目（タイトル）が未入力の場合、送信時にバリデーションエラーを表示
