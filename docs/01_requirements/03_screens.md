## 1. 画面一覧

| 画面名 | パス | 説明 |
|--------|------|------|
| トップ画面 | `/` | サービス紹介、作成への導線 |
| 作成画面 | `/create` | しおり新規作成 |
| 表示画面 | `/i/[id]` | しおり閲覧（URLを知っていれば誰でも） |

## 2. 画面遷移

```
トップ (/)
  └─[しおりを作る]→ 作成画面 (/create)
                      └─[完了]→ 表示画面 (/i/[id])

表示画面 (/i/[id])
  ├─[URLをコピー]→ クリップボードにコピー
  └─[編集]→ 合言葉チェック
              ├─ 設定なし → 編集画面へ
              └─ 設定あり → モーダルで認証 → 編集画面へ

編集画面 (/i/[id]/edit)
  ├─[更新]→ 表示画面へ
  └─[キャンセル]→ 表示画面へ
```


## 3. 各画面の詳細

### 1. トップ画面（`/`）

**要素**:
- サービス名・キャッチコピー
- サービス説明
- 「しおりを作る」ボタン（CTA）

### 2. 作成・編集画面（`/create`, `/i/[id]/edit`）

**共通フォームコンポーネント**を使用。`mode`で動作を切り替え。

| 項目 | 作成モード | 編集モード |
|------|-----------|-----------|
| ページタイトル | しおりを作る | しおりを編集 |
| フォーム初期値 | 空 | 既存データ |
| 送信ボタン | 完了 | 更新 |
| キャンセル | なし | あり（表示画面へ） |

**入力項目**:

| セクション | 項目 | 必須 |
|-----------|------|------|
| タイトル | しおりのタイトル | ✅ |
| 概要 | タイトル + 内容（複数可） | - |
| 行程 | 旅行開始日、日付、日数、時間、タイトル、交通手段、補足（複数可） | - |
| 合言葉 | 編集用パスワード | - |

> **設計方針**: 必須はタイトルのみ。行程の詳細項目もすべて任意。

**交通手段の選択肢**:
徒歩 / 電車 / バス / 飛行機 / 車 / 船 / 自転車 / タクシー / ケーブルカー

### 3. 表示画面（`/i/[id]`）

**要素**:

| セクション | 内容 |
|-----------|------|
| ヘッダー | しおりのタイトル、日付範囲（schedules の date から MIN/MAX 算出）、URLをコピー / 編集ボタン |
| 概要 | タイトル + 内容のカードリスト（shadcn/ui Card） |
| 行程 | タイムライン形式（日程バッジ + 日付、ドット + 縦線、時間、場所、補足）。交通手段アイコンはMVP未実装 |
| フッター | 削除予定日の表示（MVP未実装） |

**削除警告（フッター）**:
```
このしおりは2025年4月15日に削除されます
```
- 控えめに表示（旅行中のノイズを最小限に）
- 課金済み（`is_premium = true`）の場合は非表示（有料プランは検討中）

**合言葉認証モーダル**:
- 合言葉入力フィールド
- 確認 / キャンセルボタン
- 認証失敗時はエラーメッセージ

### 4. 掲示板（`/board`）- Phase 2

**要素**:

| セクション | 内容 |
|-----------|------|
| 投稿フォーム | タイトル + 内容 |
| リクエスト一覧 | 投票数順にソート |
| 各リクエスト | タイトル、内容、賛成ボタン、コメント |

**仕様**:
- 匿名投稿OK（アカウント不要）
- 「賛成」ボタンのみ（反対なし）
- スレッド形式（リクエスト → コメント）
- 多言語対応（日本語・英語）
- OpenAI Moderation APIで不適切投稿をフィルタ
- レートリミット（1日3件まで）


## 4. UI/UX方針

| 項目 | 方針 |
|------|------|
| レイアウト | モバイルファースト、スマホ幅固定（max-width: 480px） |
| ボタン | タップしやすいサイズ（最低44x44px） |
| PC表示 | 中央配置 |
| タイムライン | 縦方向、時系列（交通アイコンはMVP後に追加予定） |
| エラー | 分かりやすいメッセージ |
