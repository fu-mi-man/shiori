## 1. サービス概要

### サービス名

**Shiori（シオリ）**

### コンセプト

旅行の行程表を簡単に作成し、URLで共有できるWebサービス。
将来的に日本の「旅のしおり」文化を世界に届けることを見据えた、旅行行程表作成サービス。

### ターゲットユーザー

#### 主要ターゲット（Phase 1）
- 友人や家族と旅行を計画する人
- グループ旅行の幹事
- 旅行の予定を可視化したい人

#### 拡大ターゲット（Phase 2以降）
- **訪日外国人観光客**（個人旅行者）
- **民泊・ホテル等の宿泊事業者**
  - ゲストへのおもてなしツールとして活用
  - 観光ルートの提案に使用
- **世界中の旅行者**

**年齢層**: 20〜40代（スマホネイティブ世代）

**利用シーン**:
- グループ旅行の計画を立てる時
- 旅行の行程をメンバーと共有する時
- 旅行中にスケジュールを確認する時
- 民泊ホストがゲストに観光情報を提供する時

### サービスの特徴

#### 1. アカウント登録不要
- ユーザー登録なしで即座に作成開始
- メールアドレス不要
- ブラウザだけで完結

#### 2. シンプルなURL共有
- 一意のURLを生成（例: `https://shiori.app/i/abc123`）
- URLを知っている人は誰でも閲覧可能
- LINEやメールで簡単に共有

#### 3. 任意の編集保護
- 合言葉（パスワード）で編集を制限可能
- 設定しない場合は誰でも編集可能（柔軟性）

#### 4. タイムライン表示
- 時系列に沿った視覚的に美しい表示
- 交通手段アイコンで移動が分かりやすい
- 日数表示（1日目、2日目など）をサポート

#### 5. モバイルファースト
- 旅行中のスマートフォン閲覧を最優先に設計
- 作成はPCでの利用を想定、スマホでも編集可能

#### 6. グローバル対応（段階的に展開）
- 多言語対応の設計を最初から採用
- Phase 1: 日本語のみ実装
- Phase 2以降: 英語 → 韓国語 → 中国語と順次展開

### ビジネスモデル

#### 初期フェーズ
- **完全無料**
- **広告なし**（Vercel無料プランの非商用利用）
- まずは日本語版をリリースして需要を見極める

#### 将来的な展開（需要があれば）
- 多言語展開（英語 → 韓国語 → 中国語）
- Vercel Proに移行（月額$20）
- **収益化**
  - AdSense広告（しおり表示画面下部）
  - 永久保存課金（買い切り200〜300円/しおり）
  - 決済: Stripe（PayPay含む複数決済対応）
- **宿泊事業者向けの活用可能性**
  - 民泊・ホテルにおけるゲスト向け案内ツールとしての展開も視野に入れる

### 規模感

- **個人プロジェクト**
- Phase 1想定ユーザー数: 数十人〜（スモールスタート）
- 多言語展開後: グローバル展開を視野に


## 2. 類似サービスとの差別化

**「旅行中に迷わず確認できる」ことを最優先に設計した旅のしおりサービス**

- **確認体験ファースト**
  旅行中のスマートフォン閲覧を基準にUIを設計（PCでも同一レイアウト）

- **作成と確認の役割分離**
  作成はPCメイン・スマホ対応、確認体験はモバイル最適化に特化

- **即時アクセス前提**
  移動中でも待たずに表示される軽量・高速構成

- **用途特化型のミニマルUI**
  多機能・装飾前提の汎用UIを避け、
  「旅行中に必要な情報だけ」を即座に把握できる構成

- **グローバル展開を見据えた設計**
  将来的に訪日外国人観光客や世界中の旅行者が利用可能

詳細な競合比較は `99_research/benchmark.md` を参照。


## 3. プロジェクトの目的

1. **実用的なサービスを作る**
   - 自分や友人が実際に使えるサービス
   - 需要があれば多くの人に使ってもらう
   - 民泊ゲストでの実証実験も視野に

2. **技術スキルを磨く**
   - Next.js 16（App Router）の実践学習
   - TypeScript フルスタック開発の経験
   - 多言語対応(i18n)の設計・実装経験
   - Vercel デプロイとインフラ管理

3. **ポートフォリオとして活用**
   - 企画から実装、運用までの一連の経験
   - 市場価値の高い技術スタックでの開発実績
   - グローバル展開を見据えた設計経験


## 4. 今後の方針

### Phase 1: 日本語版MVP（最優先）
- 基本機能のみ実装
- **多言語対応の設計を採用**（実装は日本語のみ）
- まずはデプロイして動くものを作る
- 日本市場でユーザーフィードバックを収集

### Phase 2: 英語対応
- 翻訳ファイル追加（locales/en.json）
- 言語切り替え機能の実装
- 民泊ゲストでの実証実験
- 訪日外国人観光客の利用促進

### Phase 3: アジア言語対応
- 韓国語対応（locales/ko.json）
- 中国語対応（locales/zh-CN.json, zh-TW.json）
- アジア市場への展開

### Phase 4: グローバル展開・収益化
- その他主要言語対応
- 宿泊事業者向けB2B機能
- Vercel Pro移行
- プレミアム機能
