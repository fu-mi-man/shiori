# ライバルサービス分析

競合サービスの機能・UI/UXを分析し、差別化ポイントを明確にする。

**最終更新**: 2026年3月31日


## 市場概況

旅のしおり作成サービスは大きく2つのカテゴリに分類される：

1. **Webサービス型**（ブラウザ完結、登録不要）
   - 旅しお、しおりす、タビカンジ、TabiSync、しおりShare
2. **アプリ型**（アカウント登録必要、高機能）
   - tabiori、nicody、Wanderlog、toripo

競合は想定以上に多い。ただし**全サービスが「旅行」に特化**しており、旅行以外のカジュアルな予定共有を狙うサービスは存在しない。

本サービスは**Webサービス型**に属し、シンプルさと即時利用可能性を重視する。
将来的なピボット先として、カジュアルな予定共有ツールへの展開可能性も調査済み（詳細は「市場機会」セクション参照）。


## 終了済みサービス

### 行程さん（2020年6月終了）

**URL**: https://kouteisan.com/ （終了告知のみ表示）  
**開発者note**: https://note.com/yoshikawalog/n/n7ce35b553490

#### 開発背景（作者・吉川雅彦氏談）

- 2014年12月: 8人でスキー旅行の幹事をした際、しおり作成に苦労
- 2016年1月〜2月: 約1人月（8時間×20日）で開発
- 2017年7月25日（火曜日）リリース
- 2018年12月: 起業（投資家からの連絡がきっかけ）
- 2020年6月: サービス終了

#### なぜ人気だったか

- **圧倒的なシンプルさ**: 必要最小限の機能に絞り込み
- **登録不要**: すぐに使える気軽さ
- **迷わないUI**: 機能が絞られていて初心者でも使いやすい
- **美しい印刷レイアウト**: A4印刷時のデザインも考慮

#### ステップ数の比較（作者による分析）

競合アプリ（19ステップ）:

1. App Storeにアクセス → 2. インストール → 3. アプリを開く → 4. 説明を読む → 5. アカウント登録 → 6. 認証 → 7. 作成ボタン → 8. 項目入力 → 9. 完了 → 10. 共有ボタン → 11. 相手に送る → 12. 相手が説明を聞く → 13. 相手がApp Storeへ → 14. 相手がインストール → 15. 相手がアプリを開く → 16. 相手が説明を読む → 17. 相手がアカウント登録 → 18. 認証 → 19. しおりを確認

行程さん（8ステップ）:

1. サイトに行く → 2. 作成ボタン → 3. 項目入力 → 4. 完了 → 5. URLコピー → 6. 相手に送る → 7. 相手がアクセス → 8. しおりを確認

**→ ステップ数を減らし、大人数での共有を簡単にすることで差別化**

#### 不評だった機能

- **「next」表示**: 現在時刻に連動して次の予定を表示する機能だったが、「意味がわからない」「次の旅行という意味かと思った」という声が多く不評だった（作者談）
- → **教訓: 一見便利そうでも、直感的に理解できない機能は逆効果**

#### 機能設計の哲学（作者談）

- **「中途半端な機能は作らない」**: 中途半端に便利な機能を実装すると、必ず文句やクレームが出る
- **滞在時アイコンは作らなかった**: 選択肢が多いと面倒と感じさせるため、移動アイコンのみに絞った
- **画像アップロードは実装しなかった**: 工数削減とサーバー費用削減のため
- **必須項目を減らす**: しおり完成まで到達する人数を増やすため
- **エラーを出さない設計**: 同時刻の項目が2つ以上あってもエラーにならない

#### ユーザーヒアリングで判明した「本当の価値」

作者が想定していた価値:

- しおりを作る面倒さが解決される
- 旅行を計画どおりに進めることができる
- スケジュールを共有しやすい

**ユーザーが感じていた価値**（想定外）:

- グラフィカルに表現されることで、**理解度が上がる**
- 書くと自分の頭が整理されて**不安が消える**
- 予定をよく聞かれる**わずらわしさが減る**
- 計画段階で問題点が共有者にわかり、**旅行中の認識齟齬がなくなり喧嘩が減る**

**→ 「簡単に作る」より「簡単に共有できる」に需要があった**

#### 終了理由

- コロナ禍でPVが1/20に激減
- 個人運営の限界
- **バズって多くの人に使ってもらえたが、売上が上がらずサービス存続できなくなった**

#### 教訓

- シンプルさは強力な武器
- 機能を増やしすぎない重要性
- アカウント不要の利便性
- **継続運用のための収益モデルも考慮が必要**
- **ニッチすぎる市場は大企業が参入しない（固定費が大きすぎて赤字になるため）**

## 現行Webサービス（登録不要型）

### 1. 旅しお（tabisio.com）

**URL**: https://tabisio.com/

#### サービス概要

- 2018年11月公開
- 無料・登録不要のWebサービス
- 行程さんに近いシンプルな設計思想

#### 画面構成

- **作成・編集**: `/edit` で統合（同一URL）
- **表示**: `/siori/id/[ハッシュID]` で読み取り専用
- **URL構造**: 非常にシンプル

#### 主な機能

- 概要セクション（タイトル + 内容）
- プランセクション（開始時刻・終了時刻・日付・アイコン選択）
- 附録セクション（補足情報）
- 共同編集機能（パスワード設定）
- PDF出力対応
- URL・LINE共有

#### UI/UX特徴

- テーマカラー変更機能
- シンプルで直感的な操作
- モバイル・PC両対応

#### 強み

- URLが非常にシンプル
- 共同編集機能
- PDF出力可能
- 登録不要で即時利用

#### 弱み・改善余地

- デザインは1パターンのみ（カラー変更可）
- PDF出力は白黒になる（デザイン劣化）
- 並び替え時にバグがあるとの報告あり

#### 注意: 旅行以外への対応姿勢

旅しおは公式サイトで**「旅行・イベントなどの行程を無料で簡単に作成・シェアできる」**と謳っており、旅行以外のユースケースにも対応する姿勢を見せている。機能的にはゴルフやBBQの行程も作成可能。ただしサービス名が「旅しお」、UIもすべて旅行前提であるため、旅行以外のユーザーがこのサービスにたどり着く可能性は低い。これは**ブランディング・文脈の空白**であり、Tabijiにとっての市場機会でもある一方、旅しおが本気で「旅行以外」に舵を切った場合の潜在的リスクとして認識しておく必要がある。

### 2. しおりす（shiorisu.com）

**URL**: https://shiorisu.com/

#### サービス概要

- 行程さんの代替サービスとして人気
- 無料・登録不要のWebサービス
- 画像添付機能が特徴

#### 画面構成

- **作成・編集**: `/journey/` で統合
- **表示**: `/journey/[ID]/ja` で読み取り専用
- **URL構造**: 統合型フォーム設計

#### 主な機能

- ヘッダーカスタマイズ（3色のテンプレート：ピンク/青/黄）
- 概要セクション（タイトル + 内容）
- スケジュール管理（複数日程の時系列スケジュール）
- **マルチメディア対応**: 各スケジュール項目に画像添付可能
- アクセス制御（編集パスワード）
- しおりの複製機能
- 割り勘計算サービス「Walica」と連携（旅のしおりの本質からは外れる）

#### UI/UX特徴

- カード型レイアウトで段階的な情報入力
- Bootstrap活用でレスポンシブ対応
- セキュリティ対応（CSRF、reCAPTCHA v3）

#### 強み

- 視覚的インパクトのあるヘッダー画像
- 画像添付機能で思い出のアルバムにもなる
- 3色のテンプレート選択可能
- 割り勘連携で旅行後も便利

#### 弱み・改善余地

- やや多機能で、初心者には複雑に見える可能性
- 1年以上更新がないと自動削除
- 印刷機能は未実装（開発中とのこと）
- 並び替えは上下入れ替えの繰り返しで手間

### 3. タビカンジ（tabikanji.com）

**URL**: https://tabikanji.com/

#### サービス概要

- 2023年10月頃公開、2024年1月に大アップデート
- 「旅に持ち歩きたくなるデザイン」がコンセプト
- 印刷に力を入れている

#### 画面構成

- **作成・編集**: `/shiori/php/create.php` で統合
- **表示**: `/shiori/php/shiori.php?code=[ID]` で読み取り専用
- **履歴**: `/shiori/php/history.html` で最近見たしおりを確認可能

#### 主な機能

- 概要セクション（タイトル + 内容）
- 旅程管理（複数日程対応）
- 3種類のセキュリティモード（保護なし/編集制限/編集・閲覧制限）
- パスワードリセット機能
- **印刷専用ページ**: 綺麗なデザインのまま印刷可能
- **PDF出力機能**（2025年11月追加）
- 6つのシェアボタン（LINE/Pinterest/Facebook/X/QRコード/URL）
- **有効期限なし**: データが自動削除されない

#### UI/UX特徴

- シンプルでおしゃれなデザイン
- URL自動検出してリンク化
- ドラッグ&ドロップ不可だが、途中挿入機能あり

#### 強み

- **印刷に最適化**: 印刷専用ページあり
- **有効期限なし**: 長期保存可能
- パスワードリセット機能で安心
- 最近見たしおりの履歴機能

#### 弱み・改善余地

- ドラッグ&ドロップでの並び替え不可
- 画像添付機能なし
- デザインテンプレートは1種類

## 現行アプリ型サービス（登録必要）

### 6. tabiori（タビオリ）

**URL**: https://tabiori.com/  
**プラットフォーム**: iOS / Android / Web

#### サービス概要

- 280万ダウンロード突破（2025年時点）
- 「選ばれてNo.1旅のしおりアプリ」を謳う
- 有料プレミアム機能あり（月額480円/年額3,900円）

#### 主な機能（無料）

- スケジュール管理・共有
- **位置情報共有**: 旅行期間中のみメンバー同士で位置を共有
- 写真共有（通常画質）
- 持ち物チェックリスト
- メモ機能
- **オフライン閲覧**: 電波がなくても安心
- アプリ内チャット機能

#### プレミアム限定機能（月額480円/年額3,900円）

- **広告非表示**
- **オリジナル画質保存**: 劣化しない超高画質写真保存
- **動画共有**: 旅行の動画をメンバーと共有
- **スクラップ容量拡大**: 100MB → 10GB
- **しおりロック**: コンテンツを自分だけが編集できるロック機能
- **コンビニ印刷無料**: マルチコピー機でしおり印刷（通常会員はデータ送信料299円）
- **フォトブック注文**: カメラのキタムラと提携
- **限定スタンプ**: プレミアム限定のギフトスタンプ

#### UI/UX特徴

- 感覚的でわかりやすい操作性
- アイコンや色文字でかわいいデザイン
- PC/スマホ連携可能

#### 強み

- 機能が非常に充実
- 位置情報共有で旅行中も安心
- オフライン対応
- 高画質写真共有

#### 弱み・改善余地

- **会員登録必須**
- 一部機能は有料
- アプリのインストールが必要
- チェックリストの並び替え不可との声
- 多機能ゆえに複雑

### 7. nicody（ニコディ）

**URL**: https://nicody.jp/  
**プラットフォーム**: iOS / Web（Androidはブラウザ版）

#### サービス概要

- 50万ダウンロード突破（公式X/Instagram参照、2025年時点）
- 「令和の旅行計画アプリ」を謳う
- 特に10〜20代女性に人気
- 有料サブスク「ニコディサポーターズ」あり

#### 主な機能

- **GoogleマップAPI連携**: スポット名入力で住所・画像・営業時間が自動表示
- 行程表作成（ドラッグ&ドロップ対応）
- 地図表示（ピンで位置確認）
- **経路時間自動計算**（有料会員のみ）
- スポット検索・保存
- **ホテリエしおり**: ホテルスタッフが作った旅のしおりを閲覧可能
- メモ機能
- 共同編集（2024年5月〜ブラウザ版でAndroid対応）

#### 有料会員限定機能（ニコディサポーターズ: 月額980円/3ヶ月1,740円/年額5,700円）

- 海外旅行対応
- メモに画像アップロード
- 経路時間計算
- 定休日アラート
- スポット画像の変更
- 広告非表示

#### UI/UX特徴

- おしゃれなトップページ自動生成
- スポット検索が充実
- ドラッグ&ドロップで直感的な並び替え

#### 強み

- **スポット検索の充実**: 観光情報もアプリ内で完結
- GoogleマップAPI連携で情報自動入力
- ホテルスタッフ作成のしおりで情報収集
- 共同編集が簡単

#### 弱み・改善余地

- **会員登録必須**（後回し可能だがデータ移行に必要）
- 基本機能でも広告が多いとの声
- iOSアプリがメイン、Androidはブラウザ版のみ
- 経路計算は有料機能
- 広告の質に不満の声あり

## 本サービスの差別化戦略

### 1. 確認体験ファースト（最重要）

**「旅行中に迷わず確認できる」ことを最優先に設計**

- 競合の多くは「作成体験」に注力
- 本サービスは「確認体験」を差別化ポイントに
- 移動中でもストレスなく表示される軽量・高速構成

### 2. 行程さんの精神的後継

- 終了した行程さん・Penのシンプルさを継承
- 「すぐ使える」「迷わない」を最優先
- 必要最小限の機能に絞る

### 3. グローバル展開を見据えた設計

- 競合は日本語のみ（しおりすに英語版があるが限定的）
- 本サービスは多言語対応を設計段階から採用
- 訪日外国人観光客・民泊ゲストをターゲットに拡大可能

### 4. 最新技術スタックで高速・軽量

| 項目           | 競合（多くが該当） | 本サービス               |
| -------------- | ------------------ | ------------------------ |
| フレームワーク | jQuery/PHP/旧React | Next.js 16（App Router） |
| スタイリング   | Bootstrap/独自CSS  | Tailwind CSS v4          |
| ホスティング   | 共有サーバー       | Vercel Fluid Compute     |
| 初回表示       | 1-3秒              | 目標: 1秒以下            |

### 5. データ保持ポリシー（要検討）

- しおりす: 1年で自動削除
- しおりShare: 1年で自動削除
- タビカンジ: 有効期限なし
- **本サービス**: ビジネス状況に応じて判断
  - 無料サービスでDB容量がコストになる場合は削除ポリシーも合理的
  - ユーザー体験とコストのバランスを考慮

### 6. 段階的な機能拡張

- MVP: シンプルに始める（行程さんレベル）
- Phase 2: 掲示板、多言語対応、PDF出力、カラーテーマ
- Phase 3: 写真機能、オフライン対応、商用化

## 市場機会

### 1. 行程さん・Penの空白地帯

- 2020年6月: 行程さん終了
- 2024年10月: Pen終了
- **「シンプルで使いやすい」Webサービスの需要は依然存在**
- ただし後続サービスは多数出ており、「旅のしおり」市場は競争が激化

### 2. インバウンド需要

- 訪日外国人観光客の増加
- 民泊・宿泊事業者のゲスト向けツール需要
- **多言語対応の旅のしおりサービスは皆無**

### 3. モバイルファースト需要

- 旅行中はスマホで確認
- 競合の多くは「PC・スマホ両対応」だが「スマホ最優先」ではない
- **確認体験のモバイル最適化は差別化ポイント**

### 4. 隣接領域の競合マップ（スケジュール共有全体でのポジション）

旅のしおり系だけでなく、スケジュール共有全体の中でTabijiのポジションを俯瞰する。
「行程共有」の領域で「旅行以外」に対応するサービスは、調査の結果**存在しない**ことが確認された（2026年3月時点）。

#### カレンダー型（継続的な関係向け）

| サービス | 特徴 | 登録 |
|---|---|---|
| TimeTree | 共有カレンダー。家族・カップル・チーム向け。7,000万登録超 | 必要 |
| Urecy | タイムライン付き共有カレンダー。最大10人 | 必要 |
| Googleカレンダー | 定番。ビジネス寄り。公開URLも発行可能だがUI不親切 | 必要 |
| OurCal | グループ共有カレンダー | 必要 |
| Howbout | 友達の予定をSNS的に見られる。2026年注目株 | 必要 |

**Tabijiとの違い**: すべてアカウント登録＋アプリインストールが必須。「来週のゴルフの段取りだけ共有したい」という一回限りの用途には重すぎる。継続的な関係が前提であり、単発の予定共有には向かない。

#### 日程調整型（「いつにする？」を決める）

| サービス | 特徴 | 登録 |
|---|---|---|
| 調整さん | 日程候補を出して◯△×で投票。累計2,500万人利用 | 不要 |
| 幹事くん | 出欠管理・日程調整。忘年会等のイベント幹事向け | 不要 |
| LINEスケジュール | LINE内で日程調整。グループトーク内で完結 | LINE必要 |
| スケコン | AI活用の日程調整。Googleカレンダー連携 | 不要（一部） |

**Tabijiとの違い**: 「いつ集まるか」を決めるツール。**日程が決まった後の「当日の行程を共有する」機能は持っていない**。つまり「日程調整」と「行程共有」は別の課題であり、調整さんで日程が決まった後に「当日の流れは？」となった時に使えるツールがない。

#### LINEイベント機能

トークルーム内で予定の日時・場所を共有し、出欠確認もできるLINEの機能。手軽だが、タイムライン的な時系列表示はなく、1つのイベントに対する単発の情報共有のみ。「9時集合→10時スタート→12時昼食→14時表彰」のような流れを可視化する機能はない。また、そのトークルーム外のメンバーには共有不可。

#### 出欠確認ツール（Doorkeeper / BAND / Encountなど）

イベントの参加管理に特化。行程のタイムライン共有機能は持たない。

#### ポジションマップ

```text
  「いつにする？」       「何をいつやるか」       「日々の予定」
    日程調整               行程共有              カレンダー

    調整さん             旅のしおり系           TimeTree
    幹事くん             (全部旅行特化)         Googleカレンダー
    LINEスケジュール                            Howbout

    登録不要 ✓            登録不要 ✓            登録必要 ✗
    単発 ✓               単発 ✓               継続的 ✓
    ×行程は書けない      ×旅行UIしかない       ×重すぎる
```

**結論**: 「何をいつやるか」を登録不要で共有するサービスは旅のしおり系しかなく、それらは全て旅行UIで打ち出している。空白は**機能の空白ではなく、ブランディング・文脈の空白**である。

- 「ゴルフの行程を共有したい」→ 調整さんでは行程が書けない、TimeTreeは重い、旅のしおりは旅行っぽくて使う気にならない
- Tabijiが「予定共有」として打ち出せば、この空白に入れる可能性がある

### 5. カジュアルな予定共有の空白地帯（将来的な機会）

既存のスケジュール共有には空白地帯がある。

```text
軽い ←―――――――――――――――――――→ 重い
LINEグループ       ???        TimeTree      Googleカレンダー
「来週ゴルフね」               アプリ必須      アカウント必須
流れて消える                  継続的な関係向け
```

- **LINEグループ**: 「来週土曜ゴルフね、集合9時、場所はここ」→ 他のメッセージに埋もれて流れる
- **Googleカレンダー/TimeTree**: アカウント・アプリ必須。そこまでやるほどでもない
- **旅のしおり系サービス**: 機能的にはゴルフやBBQの予定共有にも使えるが、UIが旅行前提で作られており、サービス名もすべて「旅」「しおり」を冠している。ゴルフの予定を作ろうとは誰も思わない

**「アカウント不要、URL1つで、ちょっとした予定をちゃんと残せる」** というポジションを狙うサービスは存在しない。

#### 想定ユースケース（旅行以外）

- ゴルフの送迎・集合時間の共有
- BBQ・アウトドアの段取り共有
- 飲み会・忘年会の幹事連絡
- 日帰りの遊び・ドライブ
- 推し活イベントの参加予定
- 結婚式・法事等の行程案内

#### 差別化の本質

競合との差は**機能ではなく、見せ方と文脈**。
同じタイムライン作成機能でも「旅のしおり」という看板ではゴルフ幹事は来ない。
「一緒に過ごすひとときの予定を共有する」という文脈で打ち出すことで、同じ機能でも別のユーザー層にリーチできる。

#### 戦略

- **Phase 1**: 旅のしおりとして出す（既存市場に入り口がある）
- **その先**: 「旅行以外にも使えるじゃん」という自然な広がりを狙う
- 最初から「スケジュール共有です」と言うと「何に使うの？」となりがちなので、具体的なユースケース（旅行）から入るのが正解



## まとめ

「旅のしおり」市場は競合が多いが、確認体験・モバイルファースト・多言語対応で差別化する余地がある。

本サービスは以下で差別化を図る：

1. **確認体験ファースト**: スマホでの閲覧を最優先に設計
2. **最新技術で高速・軽量**: Vercel + Next.js 16
3. **グローバル展開**: 多言語対応を設計段階から採用
4. **シンプルな設計**: 機能を増やしすぎない
5. **将来の拡張余地**: 旅行特化で始めつつ、設計上はカジュアルな予定共有へのピボットも可能な構造を維持

**コアバリュー**:

- シンプルで迷わない
- アカウント不要ですぐ使える
- モバイルで快適に確認できる
- 視覚的に美しいタイムライン表示
- 高速・軽量
- グローバル展開可能

機能で勝負するのではなく、**「確認体験」と「シンプルさ」で差別化**する。旅のしおり市場で確固たるポジションを築くことを最優先とする。
