# サービス概要

## サービス名

**Shiori（旅のしおり作成サービス）** ※ 仮称

## コンセプト

旅行の行程表を簡単に作成し、URLで共有できるWebサービス。  
「行程さん」のようなシンプルで使いやすいUIを目指す。

## ターゲットユーザー

- 友人や家族と旅行を計画する人
- グループ旅行の幹事
- 旅行の予定を可視化したい人

**年齢層**: 20〜40代（スマホネイティブ世代）

**利用シーン**:
- グループ旅行の計画を立てる時
- 旅行の行程をメンバーと共有する時
- 旅行中にスケジュールを確認する時

## サービスの特徴

### 1. アカウント登録不要
- ユーザー登録なしで即座に作成開始
- メールアドレス不要
- ブラウザだけで完結

### 2. シンプルなURL共有
- 一意のURLを生成（例: `https://yoursite.com/i/abc123`）
- URLを知っている人は誰でも閲覧可能
- LINEやメールで簡単に共有

### 3. 任意の編集保護
- 合言葉（パスワード）で編集を制限可能
- 設定しない場合は誰でも編集可能（柔軟性）

### 4. タイムライン表示
- 時系列に沿った視覚的に美しい表示
- 交通手段アイコンで移動が分かりやすい
- 日数表示（1日目、2日目など）をサポート

### 5. モバイルファースト
- 旅行中のスマートフォン閲覧を最優先に設計
- 作成はPCでの利用を想定、スマホでも編集可能

## ビジネスモデル

### 初期フェーズ
- **完全無料**
- **広告なし**（Vercel無料プランの非商用利用）
- まずはリリースして需要を見極める

### 将来的な展開（需要があれば）
- Vercel Proに移行（月額$20）して広告・収益化を検討
- プレミアム機能の追加
- 企業向けプラン

## 規模感

- **個人プロジェクト**
- 想定ユーザー数: 数十人〜（スモールスタート）
- アクセスが集まれば段階的に拡大

## 類似サービスとの差別化

**「旅行中に迷わず確認できる」ことを最優先に設計した旅のしおりサービス**

- **確認体験ファースト**  
  旅行中のスマートフォン閲覧を基準にUIを設計（PCでも同一レイアウト）

- **作成と確認の役割分離**  
  作成はPCメイン・スマホ対応、確認体験はモバイル最適化に特化

- **即時アクセス前提**  
  移動中でも待たずに表示される軽量・高速構成

- **用途特化型のミニマルUI**  
  多機能・装飾前提の汎用UIを避け、  
  「旅行中に必要な情報だけ」を即座に把握できる構成

詳細な競合比較は `benchmark.md` を参照。

## プロジェクトの目的

1. **実用的なサービスを作る**
   - 自分や友人が実際に使えるサービス
   - 需要があれば多くの人に使ってもらう

2. **技術スキルを磨く**
   - Next.js 16（App Router）の実践学習
   - TypeScript フルスタック開発の経験
   - Vercel デプロイとインフラ管理

3. **ポートフォリオとして活用**
   - 企画から実装、運用までの一連の経験
   - 市場価値の高い技術スタックでの開発実績

## 今後の方針

1. **Phase 1**: MVP（最小限の製品）をリリース
   - 基本機能のみ実装
   - ユーザーのフィードバックを収集

2. **Phase 2**: 機能拡張（需要があれば）
   - 写真挿入
   - カラーテーマ選択
   - QRコード生成
   - PDF出力

3. **Phase 3**: 商用化検討（必要になれば）
   - Vercel Pro移行
   - 広告・収益化
   - プレミアム機能
