# ライバルサービス分析

競合サービスの機能・UI/UXを分析し、差別化ポイントを明確にする。

---

## 1. しおりす（shiorisu.com）

**URL**: https://shiorisu.com/journey/

### 主な機能
- 旅行・団体行動の計画を共有するデジタルしおり作成ツール
- ヘッダーカスタマイズ（背景画像とアイコン選択）
- 概要セクション（タイトル + 内容）
- スケジュール管理（複数日程の時系列スケジュール）
- **マルチメディア対応**（各スケジュール項目に画像等を添付可能）
- アクセス制御（編集パスワード）

### UI/UX特徴
- カード型レイアウトで段階的な情報入力
- 「概要追加」「日付を追加」「スケジュール追加」で柔軟に組み立て可能
- Bootstrap活用でレスポンシブ対応
- セキュリティ対応（CSRF、reCAPTCHA v3）

### 強み
- 視覚的インパクトのあるヘッダー画像
- 画像添付機能で視覚的に魅力的
- セキュリティ機能が充実

### 弱み・改善余地
- やや多機能で、初心者には複雑に見える可能性
- モバイルファーストというより、PC・モバイル両対応

## 2. 旅幹事（tabikanji.com）

**URL**: https://tabikanji.com/shiori/php/create.php

### 主な機能
- 旅行計画を組織・共有するプラットフォーム
- **ドラッグ&ドロップで並び替え**（概要・旅程・補足を自由に整理）
- 段階的なアクセス制御（制限なし/閲覧制限/編集制限）
- **Yahoo乗換案内との連携**（出発地・到着地・日時を直接検索）
- パスワードリセット機能（メールアドレス登録）

### UI/UX特徴
- ドラッグ&ドロップで直感的な並び替え
- 必須項目を明確化した入力フォーム
- 外部サービスとの統合による利便性向上

### 強み
- 並び替え機能で柔軟な構成
- Yahoo乗換案内連携で利便性が高い
- メールアドレス登録でパスワードリセット可能

### 弱み・改善余地
- 機能が多く、シンプルさは劣る
- メールアドレス登録が必要な点で、気軽さに欠ける

## 本サービスの差別化戦略

### 1. 圧倒的なシンプルさ
- **行程さん**の良さを継承
- 必要最小限の機能に絞る
- 初めて使う人でも迷わないUI

### 2. モバイルファースト徹底
- スマホでの使いやすさを最優先
- 固定幅デザイン（max-width: 480px）
- タップしやすいボタンサイズ

### 3. 視覚的に美しいタイムライン
- 時系列に沿った縦方向レイアウト
- 交通手段アイコンを見やすく配置
- 日数表示をサポート

### 4. 最新技術スタックで高速・軽量
- Next.js 15（App Router）
- Tailwind CSS v4
- Vercel Fluid Compute（スリープなし）
- コールドスタート最小化

### 5. 段階的な機能拡張
- MVP: シンプルに始める
- Phase 2: 需要に応じて写真機能など追加
- Phase 3: カラーテーマなど個性化機能

## 参考にする点・しない点

### 参考にする点
- **しおりす**: ヘッダー画像・アイコンのカスタマイズ（Phase 3で検討）
- **旅幹事**: 段階的なアクセス制御（合言葉の有無で実装）
- **行程さん**: 圧倒的なシンプルさ

### 参考にしない点
- **ドラッグ&ドロップ並び替え**: MVP段階では過剰機能
- **外部サービス連携**: 実装コストが高く、シンプルさを損なう
- **メールアドレス登録**: 気軽さを損なう

---

## まとめ

本サービスは、**「行程さん」のシンプルさ**を継承しつつ、**最新技術で高速・軽量**に仕上げることで差別化を図る。

**コアバリュー**:
1. シンプルで迷わない
2. アカウント不要ですぐ使える
3. モバイルで快適に使える
4. 視覚的に美しいタイムライン表示
5. 高速・軽量（Vercel + Next.js 15）

機能を増やしすぎず、**使いやすさ**にフォーカスすることが最大の差別化ポイント。
